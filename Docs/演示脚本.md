# 项目 Demo 演示脚本（画面 + 旁白 + 字幕）

> 用途：录制演示视频或现场演示，全程约 6~7 分钟。
> 每段包含：**画面**（演示什么）、**旁白**（念出来的话）、**字幕**（可打在屏幕上的关键词）。
> 旁白可以直接念，字幕可选，建议用剪辑软件把字幕放在画面下方 1/4 处、大字号。

## 录制准备

- 双窗口：左边游戏窗口，右边服务器控制台（提前跑通，字调大）
- 用全新账号演示（比如 `demo2026`），避免旧数据干扰
- 录制前自己完整跑一遍：开服务器 → 注册 → 登录 → 进迷宫 → 退出 → 重登
- 工具：OBS 录 1080p/60fps；剪辑时加字幕、转场、背景音乐

## 节奏与剪辑建议

- 全程旁白语气平稳，别赶；每段之间留 0.5 秒黑场转场
- 字幕提前写好，按段贴，别现场打字
- 服务器控制台画面出现时，把游戏窗口缩小到右侧，两个窗口同时可见更直观
- 如果视频超过 7 分钟，优先删第 4 段（任务/商店）和第 9 段设置画面，保留战斗和服务器
- 录完自己看一遍，重点检查：有没有报错日志、加载视频是否正常、字幕和旁白是否同步
