# 原神风格射击游戏 Demo（Unity）

第三人称射击 + 原神式动作系统的可游玩 Demo：登录注册、云存档、迷宫战斗、委托任务、背包装备、行为树 AI、可视化行为树编辑器，配套自研 C# TCP 服务器。

## 技术栈

- 客户端：Unity 2021.3 + C# + Input System + Cinemachine
- 服务器：C# .NET + SQLite，MVC 分层，TCP 自定义协议
- 协议：4 字节长度 + 4 字节消息 ID + UTF-8 JSON
- 编辑器拓展：GraphView 行为树节点编辑器、武器模型配置工具、宝箱动画控制器生成器

## 运行方法

1. 先启动服务器（配套仓库 `shoot-yuanshen-SERVER`，监听 8888 端口）
2. 用 Unity 打开本项目
3. 打开 `Assets/Scenes/LoginScene`，点击 Play
4. 注册账号 → 登录 → 开始游戏

打包时 Build Settings 需要包含三个场景（按顺序）：

1. `Assets/Scenes/LoginScene.unity`
2. `Assets/Scenes/SampleScene.unity`
3. `Assets/Scenes/BattleMap.unity`

## 场景结构

| 场景 | 内容 |
| --- | --- |
| LoginScene | 登录/注册/开始游戏界面，流星背景动画 |
| SampleScene | 安全区：NPC 对话、委托、商店、传送门、小地图 |
| BattleMap | 迷宫战斗地图：机关按钮开门、房间刷怪、波次刷怪、宝箱掉落 |

## 核心系统

- **玩家动作**：状态机管理待机/移动/瞄准/攀爬/闪避/滑铲/下蹲；体力系统（奔跑/攀爬/闪避消耗，升级提升上限）
- **武器系统**：多种武器数据（伤害/射速/弹匣/枪声/子弹/火花），换弹机制，枪械模型随装备切换，Animation Rigging 挂手适配
- **敌人 AI**：行为树（巡逻/追击/攻击/死亡），丘丘人近战、石头人远程丢石头、元素史莱姆弹跳/自爆；感知节流、动画参数去重
- **战斗反馈**：子弹/火花/伤害数字对象池，受击音效与动画
- **背包与装备**：武器/食物/材料，装备武器界面，食物回血/回体力（立即/间断）
- **委托任务**：接取 → 击杀/收集进度 → 提交 → 奖励，界面实时追踪
- **对话与商店**：NPC 对话系统、杂货商店
- **网络与云存档**：注册/登录/token、玩家数据上传下载（金币/背包/等级/委托/装备武器）、心跳保活
- **地图切换**：传送门加载/卸载场景，全屏加载视频（倍速播完，期间锁定输入）

## 编辑器工具（Assets/Editor）

- **行为树图编辑器**：GraphView 可视化编辑 → 导出 JSON → 运行时加载执行
- **武器模型配置工具**：从 FBX 自动匹配/填写武器模型挂点数据
- **宝箱动画控制器生成器**：一键生成宝箱 Animator Controller

## 性能优化

- 对象池：子弹、火花、伤害数字、音效播放器
- 事件驱动 UI（血量/体力/弹药/背包变更），无每帧轮询
- AI 感知 0.2s 节流、寻路 0.3s 节流、动画播放去重
- 小地图低分辨率 + 节流手动渲染（平时相机禁用）
- 图标/头像/字体/音效/BGM 缓存，加载失败也缓存（不重复加载）
- 血条/体力条 SetActive 去重、存档写盘异常保护
- 懒加载单例（Toast/委托追踪/地区提示/残血红闪/加载视频），平时零开销
